# Roadmap

## Stage 1 — trustworthy core

- [x] Define privacy boundary and evidence-first principles.
- [ ] Typed domain models for evidence, requirements, opportunities, and skill assessments.
- [ ] Deterministic validation and explainable scoring.
- [ ] Synthetic fixtures and unit tests.
- [ ] CI for tests, lint, and type checking.

## Stage 2 — evaluation

- [ ] Hand-labelled synthetic benchmark for extraction accuracy and field-level provenance.
- [ ] Metrics for precision/recall on extracted requirements, unknown-field handling, and score stability.
- [ ] Error analysis by field and failure mode.

## Stage 3 — user-facing site

- [ ] Quarto website with architecture, methodology, examples, and evaluation results.
- [ ] GitHub Pages deployment via Actions.
- [ ] Reproducible build instructions.

## Explicit non-goals for the first iteration

- Autonomous applications or recruiter outreach.
- Hiring probability predictions.
- Unreviewed scraping at scale.
- A vector database without a retrieval evaluation showing its value.
