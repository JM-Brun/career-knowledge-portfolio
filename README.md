# Career Knowledge Portfolio

An open-source demonstration of an evidence-first, privacy-aware system for career research and technical skill development.

This repository contains reusable engineering, synthetic data, evaluation methodology, and documentation. It must never contain personal career records, CVs, recruiter correspondence, private job applications, or private learning diagnostics.

## Goals

- Turn job descriptions into structured, source-backed records.
- Make skill-gap and opportunity prioritisation explainable.
- Keep unknowns explicit and separate facts from inferences.
- Evaluate extraction and scoring quality on synthetic, labelled examples.
- Demonstrate Python typing, testing, reproducibility, and maintainable design.
